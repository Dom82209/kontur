# Контур

Desktop-приложение для macOS, которое ведёт учебный процесс: входящие файлы → раскладка по предметам и неделям → версии ДЗ → итоговый файл → ручная отметка «Отправлено». Пакеты материалов для Codex и Claude.

«Контур» — локальное macOS-приложение на Tauri 2. В настоящем приложении все данные идут через реальный `TauriDesktopBridge`, SQLite и безопасный файловый сервис. `MockDesktopBridge` доступен только unit-тестам и явному browser demo.

## Запуск

```bash
npm install
VITE_KONTUR_BRIDGE=demo npm run dev  # browser demo на mock-данных
npm run build    # проверка типов (tsc -b, strict) + production-сборка в dist/
```

Desktop-оболочка (нужны Rust и Xcode Command Line Tools):

```bash
npm run tauri:dev
npm run tauri:build
```

Ручная проверка реального workflow (весь native UI работает через `TauriDesktopBridge`; IPC-ошибки не подменяются mock-результатом):

```bash
npm run tauri:dev
```

Перед импортом создайте отдельное рабочее пространство для vault либо повторно подключите ранее зарегистрированное. Простая смена пути активного vault запрещена: у каждого workspace своя SQLite и проверяемый fingerprint. Для экспериментов используйте demo workspace или отдельную тестовую папку, а не настоящий vault.

## Стек

React 19 · TypeScript strict · Vite · Motion for React (`motion/react`) · React Router (hash) · Lucide · CSS variables, собственная дизайн-система (без Tailwind) · шрифты Onest и JetBrains Mono локально через `@fontsource`.

## Экраны

| Маршрут | Экран |
|---|---|
| `/` | Главная: неделя, дедлайны, входящие, прогресс, автоматизация, провайдеры, недавние файлы |
| `/inbox` | Входящие: drag-and-drop, классификация, правка, мастер неясных файлов, предпросмотр пути, дубли, раскладка |
| `/materials` | Материалы: локальное извлечение текста и структуры (PDF, DOCX, XLSX, PPTX, TXT, MD, CSV, TSV, IPYNB, изображения), просмотр результата, подборка для анализа |
| `/subjects/:subjectId/week/:n` | Рабочее пространство недели |
| `/homework`, `/homework/:id` | Workflow-доска ДЗ и карточка ДЗ: версии, сравнение, итоговая, отправка |
| `/ai` | AI Workspace: провайдеры, материалы, редактируемый промпт, запуск, история |
| `/automation` | Правила и журнал операций с отменой |
| `/settings` | Пути, имя, шаблон имени, тема, анимации, провайдеры, безопасность |

## Сценарии для проверки

1. «Входящие» → перетащить файлы или «Симулировать загрузку».
2. Классификация идёт по одному файлу, с метром уверенности.
3. Карандаш в строке → поправить предмет / неделю / тип.
4. «Разложить автоматически» — плашки файлов перелетают в «Разложено сейчас».
5. «Домашние задания» → карточка.
6. «Новая версия» → выбрать черновик → появится v03.
7. «Сделать итоговой» → подтверждение с итоговым именем.
8. «Пакет для AI» → «Подготовить пакет» → передать вручную в официальный Claude или использовать проверенную подписочную сессию Codex CLI. API-ключи и отдельная API-тарификация не поддерживаются.
9. «Я отправила — отметить» → чекбокс подтверждения.
10. ⌘Z или «Отменить» в заголовке / тосте / журнале.
11. ⌘K — command palette.
12. Настройки → тема и анимации (или кнопка темы в заголовке).
13. «Материалы» → отметить файлы → «Извлечь текст» (прогресс, «Остановить») → открыть файл (структура, текст, метаданные, предупреждения) → «Добавить отмеченные» в подборку → «Что получит анализ».

Горячие клавиши: ⌘K палитра, ⌘Z отмена последней файловой операции, ⌘1…⌘6 разделы, ⌘, настройки.

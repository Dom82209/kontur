# Изоляция внешних AI CLI — этап 9.2

Статус: реализовано для macOS. Версия профиля изоляции: `1`. Версия схемы SQLite остаётся `7`: отчёт self-test и versioned consent хранятся в существующем безопасном `app_settings.ai_providers`.

## Граница доверия

`--sandbox read-only` у Codex ограничивает команды агента, но не запрещает самому CLI читать доступные пользователю файлы. Пустой `cwd` также не мешает обратиться к абсолютному пути. Поэтому ни `codex`, ни `claude` не запускаются напрямую: version/help/auth probe и рабочий запрос проходят через единый `IsolationRunner`.

Официальная модель угроз OpenAI для управляемых пользователем окружений также исходит из того, что процесс видит доступные окружению файлы и credentials: <https://developers.openai.com/api/docs/guides/agents-api/environments/security>.

На macOS runner проверяет канонический `/usr/bin/sandbox-exec`: владелец `root`, исполняемый файл, отсутствие group/other write. Затем применяется versioned Seatbelt-профиль `deny default` с системным базовым профилем Apple. Shell не используется; CLI и значения передаются отдельными argv, промт — через stdin.

## Файловая политика

Разрешены системные библиотеки/runtime, проверенный executable и его `.app` bundle, `/bin`, `/usr/bin` и уникальный приватный job-каталог `0700`. Только job-каталог доступен на запись. Настоящий `HOME` не передаётся: процесс получает пустой HOME внутри job. `CODEX_HOME` указывает на отдельный каталог внутри job; в нём создаётся только временная ссылка на существующий `auth.json` или `.credentials.json`. Seatbelt разрешает чтение ровно исходного credential-файла, но запрещает пользовательские `config.toml`, rules, skills, MCP и остальные файлы `.codex`. Credentials не копируются и не записываются в SQLite, DTO, события или журнал. Если `codex login status` внутри этой же изоляции не подтверждает credentials, automatic mode остаётся заблокированным.

Desktop, Documents, Downloads, проект «Контур», Obsidian vault, `.ssh`, браузерные профили, Mail, Messages, произвольные файлы HOME и каталоги других jobs остаются за пределами allowlist. Учебные материалы сначала локально превращаются приложением в текст; пути к исходникам CLI не получает.

Каждый probe и рабочий запуск получает новый job-каталог. RAII удаляет его после success, failure, cancel и timeout. Путь job не сохраняется и не эмитится. Процесс запускается в собственной process group; cancel/timeout посылает `SIGKILL` всей группе.

## Self-test и согласие

Перед включением automatic mode `run_ai_isolation_self_test` использует тот же runner и тип профиля. Fake CLI проверяет чтение/запись внутри job, запрет sentinel и записи снаружи, пользовательские каталоги и отдельно `~/.codex/config.toml`, чистое окружение, недоступность другого job, наследование sandbox дочерним процессом и уничтожение process group при cancel/timeout. Основной macOS-тест не `ignored`.

Отчёт содержит только platform, доступность runner, profile version, отдельные результаты, время и безопасное пояснение — без абсолютных путей и секретов. Consent привязан к точной версии профиля. Старое `cliEnabled=true` без версии не активирует CLI; failed self-test сбрасывает consent и блокирует send/connect.

## Провайдеры

Codex automatic mode требует фактического наличия в `codex exec --help`: `exec`, `--sandbox` с `read-only`, `--ephemeral`, `--ignore-user-config`, `--ignore-rules`, `--strict-config`, `--skip-git-repo-check`, `--output-last-message` и чтения prompt из stdin. Запуск добавляет все эти флаги. Если отсутствует любой — остаётся manual handoff.

Claude остаётся manual-only. `--tools ""` недостаточно доказывает отключение settings, hooks, MCP и slash-команд при сохранении официальной авторизации. `connect_provider("claude")` возвращает `blocked`; это не мешает независимому automatic mode Codex.

## Prompt injection и подтверждение

Промт объявляет лекции, задания, решения и комментарии недоверенными данными; запрещает выполнять вложенные инструкции, читать файлы, запускать команды и запрашивать secrets; требует конкретную JSON-схему. Это дополнительный слой, не замена OS isolation. Ответ только разбирается в черновик и меняет workflow после явного подтверждения пользователя.

## Сеть и ограничения

Профиль разрешает исходящую сеть официального CLI. Приложение не может доказать, какие серверы и телеметрию использует конкретная версия клиента; переданный текст и сеть остаются на стороне провайдера. UI не использует формулировку «полностью безопасно».

`sandbox-exec`/Seatbelt — устаревающий, недокументированный Apple-механизм и может исчезнуть или изменить поведение в будущей macOS. Любая недоступность runner или провал self-test блокирует automatic mode без fallback на обычный `Command::new(cli)`. Ручная передача остаётся рабочей. Долгосрочная альтернатива — официальный API в отдельном минимальном процессе/контейнере с явно управляемой авторизацией и egress policy.
